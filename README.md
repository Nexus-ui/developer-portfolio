# Developer Portfolio

Personal engineering portfolio showcasing **Software Engineering**, **Salesforce**, and **Agentic AI** projects.

> Project status: planning complete; application scaffolding starts in `PORT-T-005`.

## Purpose

A public technical portfolio for recruiters, engineering managers, and fellow developers. It will contain original demonstration projects, architectural case studies, and technical articles.

## Planned technology stack

- Astro, TypeScript, Tailwind CSS
- Markdown/MDX content collections
- Cloudflare Workers (static-first hosting)
- GitHub for source control and CI/CD

## Planned pages

- Home
- Projects: Salesforce, Agentic AI, Software Engineering
- Technical case studies
- Blog
- About, Resume, Contact
